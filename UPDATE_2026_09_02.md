## Ishlatish va deploy

1. Yangilangan backendni ham deploy qiling; cursor va yangi agent toollari ikkala tomonga kerak.
2. Verceldagi mavjud `VITE_API_URL` Render backendning `/api` manziliga qarasin. `OPENAI_API_KEY`, Telegram API hash yoki boshqa maxfiy kalitlarni Vercel frontend o‘zgaruvchilariga/Gitga qo‘ymang.
3. Lokal `npm ci`, `npm test -- --maxWorkers=2`, `npm run lint`, `npm run build`. Frontend Node 22.23.2 bilan test qilindi.
4. `.git` to‘liq asl nusxadan saqlandi, commit/push qilinmadi. `package.json` va lock o‘zgartirilmadi. Mavjud lokal sozlamalaringizni o‘chirmang.

## Muhim chegaralar

Ovoz uchun backenddagi mavjud OpenAI sozlamasi ishlatiladi. Yangi alohida voice key kerak emas, ammo API balans/model ruxsati va platforma voice limiti talab qilinadi. Ovoz yaratish bepul deb va’da qilinmaydi. Rasmiy speech-to-text/text-to-speech ko‘rsatmalariga mos mavjud endpointlar saqlandi; kalit serverdan chiqmaydi.

Ovoz rejimi navbatma-navbat suhbatdir: foydalanuvchi gapi tugagach matnga aylantirish, agent, keyin audio. Bu Realtime/WebRTC yoki avtomatik gap bilan uziladigan full-duplex emas. AI o‘z ovozini tasdiq deb qabul qilib yubormasligi uchun ijro paytida mikrofon yozuvi to‘xtatiladi; “Gapirish — javobni to‘xtatish” orqali navbatni olish mumkin.

Bildirishnoma ovozi sayt ochiq va brauzer audio ijrosiga ruxsat berganida ishlaydi. Sahifaga bir marta bosing; qurilmaning mute/volume holatini tekshiring. Sayt yopiq paytdagi iOS native push ovozi bu o‘zgarishga kirmaydi. Tinch vaqt qurilmaning mahalliy soati bo‘yicha. Signalning o‘zi tashqi servis/kalit talab qilmaydi.
